## 🔧 Команды запуска скриптов

### 1. Быстрый анализ БД (1-3 минуты)
```bash
python analyze_patterns_simple.py
```

**Результат:** `patterns_analysis_simple.json`

### 2. Полный анализ с файлами (10-30 минут)
```bash
# Установить дополнительные зависимости
pip install python-docx PyPDF2 requests

# Запустить
python analyze_document_patterns.py
```

**Результат:** `document_patterns_report.json`

### 3. Тестирование паттернов
```bash
python test_patterns.py
```

**Режимы:**
- `1` - Тест на 10 примерах
- `2` - Свой текст
- `3` - Показать паттерны

### 4. Генерация кода
```bash
python generate_improved_parser.py
```

**Результат:** `link_finder_improved.py`

## 🗄️ SQL-запросы

### Статистика документов
```sql
-- Общая статистика
SELECT 
    COUNT(*) as total,
    COUNT(*) FILTER (WHERE related_count > 0) as with_incoming,
    COUNT(*) FILTER (WHERE related_to IS NOT NULL) as with_outgoing
FROM documents;

-- Топ-20 по ссылкам
SELECT id, title, related_count
FROM documents
WHERE related_count > 0
ORDER BY related_count DESC
LIMIT 20;
```

### Логи поиска связей
```sql
-- Последние 10 логов
SELECT 
    document_id,
    jsonb_array_length(found_references) as refs_count,
    created_at
FROM link_finding_logs
ORDER BY created_at DESC
LIMIT 10;

-- Статистика логов
SELECT 
    COUNT(*) as total,
    COUNT(*) FILTER (
        WHERE found_references IS NOT NULL 
        AND jsonb_array_length(found_references) > 0
    ) as with_refs
FROM link_finding_logs;
```

## 🚑 Устранение проблем

### DATABASE_URL не настроен
```bash
# Проверить
echo $DATABASE_URL

# Установить (замените на свои данные)
export DATABASE_URL="postgresql://user:password@localhost:5432/mydb"

# Проверить подключение
psql $DATABASE_URL -c "SELECT 1"
```

### ModuleNotFoundError
```bash
# Проверить установленные пакеты
pip list | grep -E "psycopg2|docx|PyPDF2|requests"

# Установить недостающие
pip install psycopg2-binary python-docx PyPDF2 requests

# Проверить еще раз
python -c "import psycopg2, docx, PyPDF2, requests; print('OK')"
```

### Скрипт зависает
```bash
# Остановить (Ctrl+C)
^C

# Использовать быстрый вариант
python analyze_patterns_simple.py  # Вместо analyze_document_patterns.py
```

### Ошибка прав доступа
```bash
# Проверить права на файлы
ls -l *.py

# Сделать исполняемыми
chmod +x *.py

# Или запускать через python
python analyze_patterns_simple.py
```

## 📈 Мониторинг прогресса

### До внедрения
```sql
-- Сохранить текущую статистику
SELECT 
    COUNT(*) as total_docs,
    COUNT(*) FILTER (WHERE related_to IS NOT NULL) as with_links
FROM documents
\gset before_

\echo :before_total_docs
\echo :before_with_links
```

### После внедрения
```sql
-- Сравнить с предыдущей
SELECT 
    COUNT(*) as total_docs,
    COUNT(*) FILTER (WHERE related_to IS NOT NULL) as with_links,
    -- Вычислить прирост
    ROUND(
        (COUNT(*) FILTER (WHERE related_to IS NOT NULL)::numeric / 
         :before_with_links - 1) * 100, 
        2
    ) as improvement_pct
FROM documents;
```

```bash

alias pa-test='python test_patterns.py'
```
