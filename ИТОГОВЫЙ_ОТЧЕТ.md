## 🔍 Примеры найденных проблем

### Проблема 1: Упущенные формы глаголов

**Текст из документа:**
```
"Документы утрачивают силу с момента вступления..."
```

**Текущий парсер:** ❌ Не находит (поддерживается только "утратившим силу")

**Решение:** Добавить паттерн `r'утрачивают\s+силу'`

### Проблема 2: Обратный порядок с коротким годом

**Текст из документа:**
```
"от 15.05.24 года №456"
```

**Текущий парсер:** ❌ Не находит (поддерживается только полный год YYYY)

**Решение:** 
```python
if len(date_str.split('.')[-1]) == 2:
    date_obj = datetime.strptime(date_str, '%d.%m.%y')
    if date_obj.year > datetime.now().year:
        date_obj = date_obj.replace(year=date_obj.year - 100)
```

### Проблема 3: Множественные ссылки в скобках

**Текст из документа:**
```
"(в редакции постановлений от 01.01.2020 №1, от 02.02.2021 №2, от 03.03.2022 №3)"
```

**Текущий парсер:** ⚠️ Находит только первую ссылку (№1)

**Решение:** Специальная обработка блоков в скобках с расширенным контекстом.

### Проблема 4: Ложные срабатывания

**Тексты из документов:**
```
"телефон 8-800-123-45-67"     ❌ Ложное срабатывание
"счет №123 от 01.01.2023"     ❌ Ложное срабатывание  
"ИНН 1234567890"              ❌ Ложное срабатывание
```

**Решение:** Фильтрация контекстов с ключевыми словами: телефон, счет, банк, ИНН, ОКПО и т.п.
