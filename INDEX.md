## 🔧 Скрипты (4 файла)

### 1. **analyze_patterns_simple.py** ⭐ РЕКОМЕНДУЕТСЯ
**Назначение:** Быстрый анализ структуры БД без скачивания файлов  
**Размер:** ~9 КБ  
**Время выполнения:** 1-3 минуты  
**Зависимости:** `psycopg2-binary`  
**Запуск:**
```bash
pip install psycopg2-binary
export DATABASE_URL="postgresql://user:pass@host:5432/db"
python analyze_patterns_simple.py
```
**Результат:**
- Консольный вывод со статистикой
- Файл `patterns_analysis_simple.json`

**Что анализирует:**
- Общую статистику документов
- Топ-20 документов по количеству ссылок
- Логи поиска связей
- Цепочки связей
- Статистику по разделам

### 2. **analyze_document_patterns.py**
**Назначение:** Полный анализ с парсингом файлов  
**Размер:** ~12 КБ  
**Время выполнения:** 10-30 минут  
**Зависимости:** `psycopg2-binary`, `python-docx`, `PyPDF2`, `requests`  
**Запуск:**
```bash
pip install psycopg2-binary python-docx PyPDF2 requests
export DATABASE_URL="postgresql://user:pass@host:5432/db"
python analyze_document_patterns.py
```
**Результат:**
- Консольный вывод с подробным анализом
- Файл `document_patterns_report.json`

**Что анализирует:**
- Все из analyze_patterns_simple.py
- Реальный текст из DOCX/PDF файлов
- Контексты упоминания документов
- Частоту встречаемости паттернов
- Форматы дат и номеров

### 3. **test_patterns.py**
**Назначение:** Интерактивное тестирование regex-паттернов  
**Размер:** ~8 КБ  
**Время выполнения:** Мгновенно  
**Зависимости:** Нет  
**Запуск:**
```bash
python test_patterns.py
```
**Режимы:**
1. Протестировать на 10 готовых примерах
2. Ввести свой текст для анализа
3. Показать все поддерживаемые паттерны

**Примеры тестов:**
- "Признать утратившим силу постановление №123 от 01.12.2023"
- "Постановлением от 15.05.2024 года №456 внесены изменения..."
- "В редакции постановлений от 10.01.2020 №5, от 15.03.2021 №12..."

### 4. **generate_improved_parser.py**
**Назначение:** Генерация улучшенного кода парсера  
**Размер:** ~15 КБ  
**Время выполнения:** Мгновенно  
**Зависимости:** Нет  
**Запуск:**
```bash
python generate_improved_parser.py
```
**Результат:**
- Файл `link_finder_improved.py` с готовым кодом

**Что генерирует:**
- Функцию `parse_document_references` с 25+ паттернами
- Валидацию найденных ссылок
- Обработку специальных случаев
- Подробные комментарии
