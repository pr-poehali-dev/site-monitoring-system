## Ключевые находки

### Текущее состояние парсера

**Поддерживаемые ключевые фразы (6 паттернов):**
- утратившим силу
- признать утратившим
- внести изменения
- дополнить
- изложить в новой редакции
- в редакции постановлений

**Поддерживаемые форматы дат/номеров (3 паттерна):**
- от DATE года №NUM (обратный)
- постановление №NUM от DATE (с типом)
- №NUM от DATE (стандартный)

### Рекомендуемые улучшения

#### 1. Расширение ключевых фраз (+19 новых паттернов)

**Высокий приоритет (добавить обязательно):**
- утрачивает силу / утрачивают силу
- считать утратившим силу
- внесены изменения / вносятся изменения
- с изменениями, внесенными
- отменить / отменяется / отменен
- признать недействительным

**Средний приоритет:**
- дополняется / дополнен
- действует в редакции
- с учетом изменений
- заменить / исключить
- приостановить действие

**Низкий приоритет (для референсных ссылок):**
- на основании постановления
- во исполнение постановления
- в соответствии с постановлением

#### 2. Новые форматы дат/номеров

**Обязательно добавить:**
- Латинская 'N' вместо '№': `N 123 от DATE`
- Символ решетка: `# 123 от DATE`
- Короткий год с коррекцией: `№123 от 15.05.23` → проверка века
- Списки в скобках: `(в редакции ... от DATE1 №NUM1, от DATE2 №NUM2)`

**Желательно добавить:**
- Номер без символа: `постановление 123 от DATE`
- Диапазоны: `№10-15 от DATE` → разворачивать в список
- Месяц словами: `от 1 января 2023 года №123`

#### 3. Валидация и фильтрация

**Критически важно:**
- Фильтр номеров (не более 6 цифр)
- Фильтр дат (1990 ≤ год ≤ текущий_год + 1)
- Исключение технических номеров (телефон, счет, ИНН и т.п.)

**Желательно:**
- Приоритизация результатов (отмена > изменения > ссылки)
- Проверка на вложенность в кавычки (исключать цитаты)

## Особые случаи

### 1. Множественные ссылки в одном контексте

**Проблема:**
```
"в редакции постановлений от 01.01.2020 №1, от 02.02.2021 №2, от 03.03.2022 №3"
```

**Решение:**
- Увеличить контекстное окно для фраз с "редакции"
- Применять паттерны ко всему окну, а не только к первому совпадению

### 2. Обратный порядок (от DATE №NUM)

**Проблема:**
Часто встречается формат "от 15.05.2024 года №123", но он может быть пропущен.

**Решение:**
Добавить паттерн с приоритетом выше стандартного.

### 3. Короткий год (YY вместо YYYY)

**Проблема:**
Дата "15.05.23" может интерпретироваться как 2023 или 1923.

**Решение:**
```python
if date_obj.year > datetime.now().year:
    date_obj = date_obj.replace(year=date_obj.year - 100)
```

### 4. Ложные срабатывания

**Типичные случаи:**
- Телефоны: "8-800-123-45-67"
- Счета: "счет №123 от 01.01.2023"
- ИНН/ОГРН: "ИНН 1234567890"

**Решение:**
Исключать контексты, содержащие слова: телефон, счет, банк, ИНН, ОКПО, СНИЛС и т.п.

## Полезные команды

### Анализ базы данных

```sql
-- Количество документов с входящими ссылками
SELECT COUNT(*) FROM documents WHERE related_count > 0;

-- Топ-20 документов по количеству ссылок
SELECT id, title, related_count 
FROM documents 
WHERE related_count > 0 
ORDER BY related_count DESC 
LIMIT 20;

-- Статистика логов поиска связей
SELECT 
    COUNT(*) as total,
    COUNT(*) FILTER (WHERE found_references IS NOT NULL) as with_refs
FROM link_finding_logs;

-- Самые длинные цепочки связей
WITH RECURSIVE chains AS (
    SELECT id, related_to, 1 as depth
    FROM documents
    WHERE related_count > 0
    UNION ALL
    SELECT d.id, d.related_to, c.depth + 1
    FROM documents d
    JOIN chains c ON c.id = d.related_to
    WHERE c.depth < 10
)
SELECT MAX(depth) as max_chain_length FROM chains;
```
