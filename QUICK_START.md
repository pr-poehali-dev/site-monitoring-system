# Быстрый старт: Анализ паттернов документов

## Что это?

Набор скриптов для анализа паттернов упоминания предыдущих версий документов в базе данных системы мониторинга.

## Зачем?

Улучшить логику автоматического поиска связей между документами, чтобы система находила больше связей и делала это точнее.

---

## Вариант 1: Самый быстрый (1 минута)

**Для тех, кто хочет быстро оценить ситуацию**

```bash
# Установить зависимость
pip install psycopg2-binary

# Настроить DATABASE_URL (замените на ваши данные)
export DATABASE_URL="postgresql://username:password@host:5432/database"

# Запустить анализ
python analyze_patterns_simple.py
```

**Что получите:**
- Статистика по документам и связям
- Топ-20 документов по количеству ссылок
- Анализ логов поиска связей
- Рекомендации по улучшению

**Время выполнения:** ~1-3 минуты

---

## Вариант 2: Полный анализ (30 минут)

**Для глубокого изучения паттернов**

```bash
# Установить все зависимости
pip install psycopg2-binary python-docx PyPDF2 requests

# Настроить DATABASE_URL
export DATABASE_URL="postgresql://username:password@host:5432/database"

# Запустить полный анализ
python analyze_document_patterns.py
```

**Что получите:**
- Все из Варианта 1
- Реальные примеры текстов из документов
- Частоту встречаемости каждого паттерна
- Примеры контекстов упоминания
- Подробный JSON-отчет

**Время выполнения:** ~10-30 минут

---

## Вариант 3: Тестирование паттернов (мгновенно)

**Для проверки работы regex на примерах**

```bash
# Запустить интерактивный тестировщик
python test_patterns.py
```

**Выберите режим:**
- `1` - Протестировать на 10 готовых примерах
- `2` - Ввести свой текст для тестирования
- `3` - Показать все поддерживаемые паттерны

**Время выполнения:** Мгновенно

## Что делать дальше?

### Шаг 1: Изучить результаты

```bash
# Просмотреть краткий отчет
cat patterns_analysis_simple.json | jq '.stats'

# Посмотреть топ документов
cat patterns_analysis_simple.json | jq '.top_referenced_documents'

# Изучить найденные паттерны (если запускали полный анализ)
cat document_patterns_report.json | jq '.patterns'
```

### Шаг 2: Прочитать рекомендации

```bash
# Открыть в любом Markdown-редакторе
less pattern_improvements_recommendations.md

# Или открыть в браузере (если есть Markdown preview)
open pattern_improvements_recommendations.md
```

### Шаг 3: Сгенерировать улучшенный код

```bash
python generate_improved_parser.py
```

Это создаст файл `link_finder_improved.py` с готовым кодом.

### Шаг 4: Внедрить изменения

1. Открыть `backend/link-finder/index.py`
2. Найти функцию `parse_document_references`
3. Заменить её на версию из `link_finder_improved.py`
4. Протестировать на тестовых данных
5. Развернуть в production

## Устранение проблем

### Ошибка: DATABASE_URL не настроен

```bash
# Проверить
echo $DATABASE_URL

# Установить (замените на свои данные)
export DATABASE_URL="postgresql://user:password@localhost:5432/mydb"
```

### Ошибка: ModuleNotFoundError

```bash
# Установить недостающие пакеты
pip install psycopg2-binary python-docx PyPDF2 requests
```

### Скрипт выполняется слишком долго

Используйте быстрый вариант:
```bash
python analyze_patterns_simple.py  # Вместо analyze_document_patterns.py
```

### Нет доступа к базе данных

1. Проверьте правильность DATABASE_URL
2. Убедитесь, что база доступна по сети
3. Проверьте права доступа пользователя

## Полезные команды

### Анализ статистики

```bash
# Сколько документов с входящими ссылками
psql $DATABASE_URL -c "SELECT COUNT(*) FROM documents WHERE related_count > 0;"

# Топ-10 по количеству ссылок
psql $DATABASE_URL -c "
  SELECT title, related_count 
  FROM documents 
  WHERE related_count > 0 
  ORDER BY related_count DESC 
  LIMIT 10;
"
```

### Просмотр логов

```bash
# Последние 10 логов поиска связей
psql $DATABASE_URL -c "
  SELECT document_id, 
         jsonb_array_length(found_references) as refs_count,
         created_at
  FROM link_finding_logs 
  ORDER BY created_at DESC 
  LIMIT 10;
"
```
